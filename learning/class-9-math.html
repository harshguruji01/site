Polynomials & Algebra Practice

Solve these questions and click "Show Solution" to verify your answers.

1. Factorize: x² + 7x + 12
Step 1: Find two numbers that multiply to 12 and add to 7. (These are 3 and 4).
Step 2: Rewrite the middle term: x² + 3x + 4x + 12
Step 3: Group terms: x(x + 3) + 4(x + 3)
Answer: (x + 3)(x + 4)
2. If p(x) = 5x - 4x² + 3, find the value of p(0).
Step 1: Substitute x = 0 into the polynomial.
Step 2: p(0) = 5(0) - 4(0)² + 3
Step 3: p(0) = 0 - 0 + 3
Answer: 3
3. Check whether x+1 is a factor of x³ + x² + x + 1.
Step 1: Use the factor theorem. Let x + 1 = 0 ➔ x = -1.
Step 2: Substitute x = -1 into p(x).
Step 3: p(-1) = (-1)³ + (-1)² + (-1) + 1 = -1 + 1 - 1 + 1 = 0.
Answer: Yes, since remainder is 0, x+1 is a factor.
